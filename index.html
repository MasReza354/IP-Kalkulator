MAC Address vs IPv4 Address

Identitas Fisik Pabrik vs Alamat Lokasi Jaringan

badge MAC Address (KTP/Nomor Seri Fisik Perangkat):

MAC (Media Access Control) adalah nomor sertifikat/KTP fisik yang diukir permanen oleh pabrik pada chip WiFi atau kartu LAN perangkat Anda. Sifatnya unik secara global di dunia.

  • Bekerja di Layer 2 (Data Link OSI).
  • Format 48-bit (6 pasang kode Hexadecimal, misal: 94-18-82-08-1D-5B).
  • 3 pasang pertama = Kode Pabrik Vendor (OUI), 3 pasang akhir = Seri Unik Perangkat.
lan IPv4 Address (Alamat Surat / Nomor Kamar):

IPv4 adalah alamat jaringan sementara yang diberikan agar perangkat Anda bisa berkirim data lewat internet. Alamat ini bisa berubah jika Anda pindah lokasi WiFi.

  • Bekerja di Layer 3 (Network OSI).
  • Berukuran 32-bit (sekitar 4,3 miliar kombinasi unik).
  • Format Desimal 4 bagian: 192.168.1.1.

NetID vs HostID (Struktur Biner)

Identitas Kelompok Jaringan vs Identitas Perangkat

Setiap alamat IPv4 (32 bit biner) terbagi menjadi dua porsi utama:

Network ID (NetID): Menunjukkan nama kelompok/jalan tempat jaringan berada. Bit biner bernilai `1` pada subnet mask.
Host ID (HostID): Menunjukkan nomor unik perangkat di dalam kelompok tersebut. Bit biner bernilai `0` pada subnet mask.

Mengapa Formula Usable Host = 2(32-n) - 2?

Dua Alamat Spesial yang Dipesan Sistem Jaringan

Dari total kombinasi alamat IP dalam satu subnet, 2 IP selalu dipesan khusus dan tidak boleh dikonfigurasi pada komputer/HP user:

  • 1. Alamat Network (IP Pertama): Digunakan router sebagai nomor ID kelompok jaringan.
  • 2. Alamat Broadcast (IP Terakhir): Digunakan untuk menyiarkan pesan ke seluruh perangkat di subnet sekaligus.
Rentang IP Usable yang aman dipakai = First Host (Network + 1) s/d Last Host (Broadcast - 1).

Pengantar & Panduan Mengisi Lembar Kerja (Worksheet) Subnetting

Modul panduan langkah-demi-langkah bagi siswa / pemula untuk menyelesaikan tabel matriks tugas jaringan

lightbulb Bagaimana Cara Mengisi Matriks Tabel Tugas Jaringan?

Jika Anda mendapatkan lembar kerja (worksheet) berisi daftar IP Network/Prefix dan diminta mengisi parameter seperti IP Private/Public, IP Class, IP Network, Host Start, Broadcast, IP Total Host, dan Netmask — ikuti 4 aturan praktis di bawah ini:

fact_check 1. Menentukan IP Private/Public & IP Class

Cukup perhatikan Oktet Pertama (Angka Paling Depan) pada IP:

  • • 10.x.x.x = Private (Class A)
  • • 172.16.x.x s/d 172.31.x.x = Private (Class B)
  • • 192.168.x.x = Private (Class C)
  • • Di luar rentang di atas = Public
Kategori Kelas: Class A (1-126), Class B (128-191), Class C (192-223).

calculate 2. Menentukan Netmask & IP Total (Host)

Lihat angka Notasi Prefix /n di belakang IP:

  • • Sisa Bit Host ($H$) = $32 - n$
  • • IP Total (Host Usable) = $2^H - 2$
  • • Netmask = Format desimal 4-oktet dari bit 1 sebanyak $n$. (Lihat tab Tabel CIDR untuk referensi cepat).

numbers 3. Menentukan Network, Host Start, & Broadcast

Alokasi alamat IP di dalam blok subnet:

  • • IP Network = Alamat terdepan (semua host bit = 0)
  • • IP Host Start = IP Network + 1
  • • IP Broadcast = Alamat terbelakang (semua host bit = 1)
  • • IP Host End = IP Broadcast - 1

autorenew 4. Soal Dibalik (Diketahui Kebutuhan Host)

Jika soal menentukan jumlah IP Total (Host):

  • 1. Cari pangkat 2 terkecil ($2^H - 2$) yang mencukupi.
  • 2. Notasi Prefix = $32 - H$.
  • 3. Contoh: Butuh 500 Host $\rightarrow$ $2^9 - 2 = 510 \ge 500 \rightarrow H=9 \rightarrow$ Prefix **`/23`**.

assignment Contoh Kasus Pengisian Matriks (Soal: 172.20.10.0/27)
