MAC Address vs IPv4 Address

Identitas Fisik Pabrik vs Alamat Lokasi Jaringan

💳 MAC Address (KTP/Nomor Seri Fisik Perangkat):

MAC (Media Access Control) adalah nomor sertifikat/KTP fisik yang diukir permanen oleh pabrik pada chip WiFi atau kartu LAN perangkat Anda. Sifatnya unik secara global di dunia.

  • Bekerja di Layer 2 (Data Link OSI).
  • Format 48-bit (6 pasang kode Hexadecimal, misal: 94-18-82-08-1D-5B).
  • 3 pasang pertama = Kode Pabrik Vendor (OUI), 3 pasang akhir = Seri Unik Perangkat.
🌐 IPv4 Address (Alamat Surat / Nomor Kamar):

IPv4 adalah alamat jaringan sementara yang diberikan agar perangkat Anda bisa berkirim data lewat internet. Alamat ini bisa berubah jika Anda pindah lokasi WiFi.

  • Bekerja di Layer 3 (Network OSI).
  • Berukuran 32-bit (sekitar 4,3 miliar kombinasi unik).
  • Format Desimal 4 bagian: 192.168.1.1.

IP Private vs IP Public

Nomor Kamar Hotel Intern vs Alamat Gedung Utama

🏡 IP Private (Jaringan Internal Rumah/Kantor):

Alamat internal gratis yang dipakai khusus di dalam jaringan lokal WiFi rumah Anda. Orang luar dari internet tidak bisa mengakses IP ini secara langsung demi keamanan.

Rentang IP Private Resmi:
• Kelas A: 10.0.0.0 s/d 10.255.255.255
• Kelas B: 172.16.0.0 s/d 172.31.255.255
• Kelas C: 192.168.0.0 s/d 192.168.255.255
🌍 IP Public (Alamat Resmi Internet Dunia):

Alamat unik global yang diberikan oleh Provider Internet (Indihome/Biznet/Telkomsel). Ini adalah alamat yang tampak oleh Google atau YouTube saat Anda berselancar di internet.

IP Statik vs IP Dinamik (DHCP)

Nomor Rumah Tetap vs Nomor Antrian Otomatis

🔄 IP Dinamik (DHCP Server):

IP yang dipinjamkan secara otomatis oleh Router saat Anda menyalakan WiFi. Mirip seperti nomor antrian minimarket — alamat IP ini bisa berganti-ganti tiap kali Anda terhubung ulang.

📌 IP Statik (Diatur Manual):

IP yang dikunci dan diketik secara manual pada perangkat. Biasanya dipakai pada Server Website, Printer Kantor, atau Kamera CCTV agar lokasinya tetap dan tidak membuat bingung perangkat lain.

NetID vs HostID (Struktur Biner)

Identitas Kelompok Jaringan vs Identitas Perangkat

Setiap alamat IPv4 (32 bit biner) terbagi menjadi dua porsi utama:

Network ID (NetID): Menunjukkan nama kelompok/jalan tempat jaringan berada. Bit biner bernilai `1` pada subnet mask.
Host ID (HostID): Menunjukkan nomor unik perangkat di dalam kelompok tersebut. Bit biner bernilai `0` pada subnet mask.

Mengapa Formula Usable Host = 2(32-n) - 2?

Dua Alamat Spesial yang Dipesan Sistem Jaringan

Dari total kombinasi alamat IP dalam satu subnet, 2 IP selalu dipesan khusus dan tidak boleh dikonfigurasi pada komputer/HP user:

  • 1. Alamat Network (IP Pertama): Digunakan router sebagai nomor ID kelompok jaringan.
  • 2. Alamat Broadcast (IP Terakhir): Digunakan untuk menyiarkan pesan ke seluruh perangkat di subnet sekaligus.
Rentang IP Usable yang aman dipakai = First Host (Network + 1) s/d Last Host (Broadcast - 1).

shield Wildcard Mask & IP Khusus (Localhost 127.0.0.1)

Wildcard Mask: Merupakan kebalikan biner (*inversi*) dari Subnet Mask (misal mask 255.255.255.0 memiliki wildcard 0.0.0.255). Digunakan dalam pembuatan aturan Firewall, Router Cisco, dan Mikrotik Access List (ACL).

IP Localhost (127.0.0.1): Alamat IP khusus *Loopback* yang merujuk pada perangkat itu sendiri, biasanya dipakai pengembang untuk menguji aplikasi web lokal.

lightbulb Mengapa Metode CIDR (Subnetting) Sangat Penting?

Dahulu, sistem pengalamatan IP terbagi kaku menjadi Kelas A, B, dan C. Namun jika sebuah kantor membutuhkan 300 komputer, mereka terpaksa harus menyewa 1 blok Kelas B (65.534 IP), sehingga membuang lebih dari 65.000 IP secara cuma-cuma!

Dengan metode CIDR (Classless Inter-Domain Routing) atau Notasi Prefix (seperti /23 atau /24), jaringan dapat dipotong secara fleksibel dan presisi sesuai jumlah komputer yang dibutuhkan tanpa ada alamat IP yang terbuang sia-sia.
